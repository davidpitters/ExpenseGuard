# 0003 — Use the official Responses API

Status: accepted for implementation · 2026-10-02

The live provider will use the official OpenAI .NET package (2.14.0) and Responses API behind a model-provider interface. Milestone 0 pins the package without creating a model client or requesting credentials. Live integration is milestone 6; model selection is explicit configuration.

Reference: https://developers.openai.com/api/docs/libraries
