# Versioned prompt assets

Milestone 0 design assets; not wired to a model and not yet evaluated. Version changes require evaluations once milestone 9 exists. The public operating contract is not an authorization mechanism. Keep model input isolated from untrusted document/tool fields. Never request or persist private reasoning.

Milestones 6–7 will add executable extraction, recommendation and clarification JSON schemas alongside their validators and regression cases. Do not create permissive schemas before the corresponding domain contracts exist.
